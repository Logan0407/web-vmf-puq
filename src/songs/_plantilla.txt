# Cómo funciona este archivo
#
# 1. Los datos van arriba entre llaves. Solo "title" es obligatorio,
#    pero sin "key" el capo no sabe desde qué tono transponer.
#
# 2. En "youtube" va solo el ID del video, no la URL completa:
#      https://www.youtube.com/watch?v=dQw4w9WgXcQ  ->  dQw4w9WgXcQ
#
# 3. Las secciones se abren con == Nombre == y el nombre aparece
#    en pantalla como etiqueta. Sirve para que el grupo sepa dónde
#    está parado cuando le dices "vamos al puente".
#
# 4. Los acordes van en su propia línea, encima de la letra, en la
#    columna donde cae el cambio. Cuenta los caracteres, no los
#    tabs: un tab en Word no equivale a una posición fija.
#
# 4b. Sirven las dos notaciones:
#       inglesa:  C  D  E  F  G  A  B     (Am, F#m7, Csus4, G/B)
#       latina:   Do Re Mi Fa Sol La Si   (Lam, Fa#m7, Dosus4, Sol/Si)
#
#     La capitalización importa: "Sol" es un acorde, "sol" es una
#     palabra. Escribe siempre la primera letra en mayúscula.
#
#     El menor se escribe pegado: Lam, Mim, Fa#m. También sirve
#     Lam7, Dosus4, Domaj7, Do/Sol.
#
#     Puedes tener unas canciones en inglés y otras en solfeo sin
#     problema, pero no conviene mezclar las dos dentro de la misma
#     canción: funciona, pero al transponer queda a medio camino
#     entre las dos notaciones y confunde al que lee.
#
# 5. Una sección puede tener solo acordes y ninguna letra
#    (un intro o un puente instrumental). Se muestra tal cual.
#
# 6. Este archivo empieza con _ , así que renómbralo al copiarlo.
#    El nombre del archivo define la dirección de la canción:
#    gracia-sublime-es.txt  ->  /#/gracia-sublime-es
# ------------------------------------------------------------------
